**Methode :**
Pour chaque candidat :
1. Fetch le site (et les sous-pages programme : /programme, /projet, /nos-engagements, /propositions, etc.)
2. Si le site est JS-only ou vague, chercher dans la presse locale avec WebSearch : "[nom] [ville] programme municipales 2026"
3. Extraire les propositions concretes (pas de declarations vagues)
4. Les mapper aux sous-themes : "categorie/sous-theme"
5. Ecrire scripts/tmp_{candidat_id}_props.json
6. Executer : python scripts/inserer_propositions.py --ville {ville_id} --candidat {candidat_id} --file scripts/tmp_{candidat_id}_props.json

**Format du JSON :**
```json
{
  "categorie/sous-theme": {
    "texte": "Description de la proposition",
    "source": "Programme officiel",
    "sourceUrl": "https://url-source"
  }
}
```
